# فندق السلامي — Android Project

هذا مشروع Android جاهز للفتح في Android Studio.

## التشغيل
1. افتح مجلد `hotel_alsalami_android` في Android Studio.
2. انتظر Gradle Sync.
3. شغّل التطبيق على هاتف Android أو Emulator.
4. لبناء APK: من Android Studio اختر **Build > Build APK(s)**.

## الوظائف
- 10 غرف مع عدد الأسرة الثابت.
- عدد الأشخاص مستقل عن عدد الأسرة.
- معلومات النزلاء تُضاف يدويًا وبشكل منفصل.
- حساب السعر والليالي والمدفوع والباقي.
- سجل الحجوزات والإعدادات.
- وقت الخروج الرسمي 12:00 ظهرًا.
- تنبيه محلي على الهاتف الساعة 10:00 صباحًا يوم الخروج.
- التنبيه يستمر بعد إغلاق التطبيق، ويعاد ضبطه بعد إعادة تشغيل الهاتف.

ملاحظة: أول بناء يحتاج إنترنت لتنزيل Android Gradle Plugin وGradle إذا لم تكن موجودة في جهازك.
